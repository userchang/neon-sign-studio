# Neon Sign Studio · 3D 无限镜面霓虹灯牌生成器

受 X 上经典的 3D 无限镜面霓虹动图启发，使用纯前端 **WebGL + Canvas 2D** 实现零依赖、实时渲染与动图导出小工具。

## 打开方式

- **方式一（推荐）**：直接双击打开 `index.html`（无模块化跨域限制，开箱即用）。
- **方式二**：在当前目录下运行任意本地静态服务器，例如：
  ```bash
  python -m http.server 8765
  ```
  然后访问 `http://localhost:8765`。

## 功能特性

- **文字与灯管定制**：
  - 默认内置还原原版的 **经典霓虹矢量灯管**（含标志性菱形 `O` 与空心轮廓 `NEON`），同时支持任意中文、英文、数字及多行文字输入。
  - 可切换 **空心灯管 / 实心灯管 / 双层灯管** 与 **圆角矩形 / 胶囊形 / 双线框 / 切角牌 / 霓虹底线 / 无边框**，并支持字号、字距、粗细、留白实时微调。
- **光效与无限镜面景深**：
  - 提供 8 套精选霓虹主题（默认同款玫粉、赛博青蓝、日落珊瑚、电光紫夜、酸性薄荷、复古琥珀、蒸汽波双色、流光幻彩），支持自由取色与 4 种色彩混合模式。
  - 支持 1–16 层真 3D 透视虚拟倒影叠加，可调层间距、衰减率、多级 GPU 高斯辉光（Bloom）、灯芯亮度与电流闪烁模式。
- **运动方式与交互**：
  - 8 种 3D 运动预设：**左右摇摆（默认同款）、8 字漂浮、上下俯仰、360° 旋转、自由悬浮、节拍律动、鼠标跟随、静止展示**，且画布支持直接拖拽偏转视角。
- **导出分享**：
  - 支持导出高清 **PNG** 静帧、内置纯 JS 编码的无缝循环 **GIF** 动图，以及浏览器硬件流录制的 **WebM** 视频。
